Local Operator Mobile drives the agent sessions running on your computer.

You start work on your machine. Then you leave the desk. This app is how you keep the work going: it shows you what each session is doing and lets you answer it.

WHAT IT DOES
- Your sessions, live: every session running on your computer, with what each one is doing.
- The transcript as it happens: messages, tool calls, and their results.
- Steer and stop: send a follow-up to redirect a running agent, or stop it.
- Approve and answer: the agent asks before it acts, and you answer from the phone.
- Model and effort: switch a session's model and how hard it thinks.
- Slash commands: the session's own commands, with suggestions while you type.
- Subagents: see which subagents a session started and follow each one.
- To-dos: the task list a session is working through.
- Past sessions: search earlier work and pick it up again.
- New session: start a session in a folder on your computer.
- Image attachments: send a screenshot into a session.

HOW IT CONNECTS
Local Operator's mobile relay runs on your computer and only ever listens locally. The app reaches it through a tunnel. Set it up either way:
- Sign in with Radient and the app finds your tunnels for you. The tunnel handles authentication, so there is no separate relay password to copy.
- Or point the app at any tunnel or URL you run yourself, and sign in with the relay password.

YOUR FILES STAY ON YOUR COMPUTER
The agents run on your computer, with your files and your tools. This app is a client: it does not move your work anywhere. Nothing is uploaded, and there is no second copy of your project in the cloud.

FREE AND OPEN SOURCE
Local Operator Mobile is MIT licensed, and so is the Local Operator agent it talks to. You can read the code, build it yourself, or run it from a tunnel you control.

REQUIREMENTS
- A computer running Local Operator (macOS, Windows or Linux).
- Local Operator's mobile relay enabled on that computer.
- A tunnel: a Radient personal tunnel, or one you run yourself.
