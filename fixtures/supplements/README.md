# Turn-supplement contract fixtures (vendored, byte-exact)

These are **byte-exact copies** of the C0 contract fixtures generated by
`local-operator`'s `tests/fixtures/supplements/build.py`
(`tests/fixtures/supplements/**`, read from `origin/main` `90fad1d8` on
2026-10-11). They are vendored rather than re-typed for the reason the
corpus README gives for every capture — a hand-built sample mistaken for a
generated one is how a test starts asserting the wrong wire — and copying them
verbatim is what lets this repo assert the same bytes the TUI, UI and relay-web
lanes assert:

| what | file(s) | this repo's consumer asserts |
|---|---|---|
| one durable journal row per state (`{id, ts, type:"custom", payload:{custom_type:"supplement_v1", details}}`) | `rows/*.json` | `payload.details` IS the projection's `supplements` map value on a cold open (`mobile/daemon.py` `_durable_projection`), so the reader and the disposition matrix are driven from the real generated row, not a fixture of my own making |
| what every surface must paint per row, live vs cold | `rows/dispositions.json` | `supplementDisposition` agrees for every row, both `jobLive` readings — the cross-surface contract (`rows/queued_stale.json` is THE stale-row fixture) |
| host↔frame message shapes, accepted and rejected, and the nonce boundary | `messages/messages.json` | `acceptFrameMessage`'s acceptance rule, driven shape by shape from the fixture |
| one assembled document | `documents/populated.html` | the native shim's output against the real assembled bytes (CSP intact, otherwise byte-identical, idempotent) and the web mount URL's base64 round-trip |

Two deliberate departures from `fixtures/relay/**`'s house conventions:

1. **This directory is NOT the relay corpus, and does not live in it.** Every
   JSON under `fixtures/relay/**` must carry a `provenance` object whose `kind`
   the directory implies ("live" for a capture, "synthetic" for a built
   sample). These files are neither: they are another repo's generator output,
   pinned byte-for-byte, and a marker added here would break both the byte
   fidelity and the owning repo's `build.py --check` drift gate. The corpus's
   own tests (`src/contracts/__tests__/schemas.test.ts`,
   `src/testing/__tests__/fixtures.test.ts`) scan `fixtures/relay/**` and
   deliberately do not reach this directory; this README is the provenance.
2. **One directory, not a flat corpus.** The mock relay's loader
   (`tools/mock-relay/fixtures.ts`) scans `fixtures/relay/http/`, `sse/`,
   `synthetic/` and `gateway/` by name, so nothing in the mock relay or the
   audit reads these — they exist for the unit suite
   (`src/features/session/supplements.test.ts`).

To refresh after a contract change: re-copy from
`local-operator/tests/fixtures/supplements/` after its `build.py` regenerates
them, and update the ref in this README. A mismatch in either direction is a
bug in one of the two repos, not a reason to edit a file here.
