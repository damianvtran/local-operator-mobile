A root the harness cannot move

Every size on this page is in rem, so it doubles when the root font size doubles — and the root cannot double here, because the stylesheet pins it with `!important`.

The harness sets the root inline before each capture, once at 16 px and once at 32 px, and both captures come back identical. That is what makes this page the control for the guard's own precondition rather than for any one role.

Without the root assertion the per-role comparison divides each frame by that frame's own root and reports the pair live, which is how a guard that exists to catch non-scaling text would pass text that never scaled.
