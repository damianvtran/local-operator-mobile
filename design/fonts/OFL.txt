Local Operator app — font licences

The three typefaces the mobile app ships are all licensed under the SIL Open
Font License, Version 1.1. The OFL permits bundling, embedding in an installed
application, subsetting and redistribution, including commercially, with two
obligations: keep the copyright and licence notice with the font files, and do
not sell the fonts on their own.

This file discharges the first obligation. It carries the three upstream
copyright notices VERBATIM, followed by the full licence text, which is
identical for all three.

| JetBrains Mono | OFL-1.1 | 2020 The JetBrains Mono Project Authors | github.com/JetBrains/JetBrainsMono | v24 |
| Fraunces | OFL-1.1 | 2018 The Fraunces Project Authors | github.com/undercasetype/Fraunces | v38 |

Notes taken when this file was assembled (2026-09-29):

- The three notices are copied from each project's own OFL.txt at its upstream
  repository, unedited.
- The licence body is byte-identical across the three upstream copies except for
  one URL: the Figtree and Fraunces copies point at
  http://scripts.sil.org/OFL and the JetBrains Mono copy at
  https://openfontlicense.org (the same SIL OFL 1.1 text). Both URLs are
  therefore recorded above the body below.
- Fraunces is not rendered in the app's UI. It is still listed here because the
  store listing, the onboarding's first frame and the launch screen use it, and
  the OFL obligation follows the file wherever it ships.
- Copy this file, or the notices below, next to any font files an
  implementation pass bundles (for example an Expo asset directory). Keeping the
  notices with the fonts is the obligation; this file is where they live in the
  repository.
- Do not rename the families in a way that suggests they are ours: the OFL's
  Reserved Font Name clause is the one people trip on.
